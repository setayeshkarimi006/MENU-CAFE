# ☕ Setayesh Cafe — Modern Menu UI

A modern, responsive, and interactive digital menu for **Setayesh Cafe**, built with pure **HTML, CSS, and JavaScript**.

This project focuses on creating a clean and elegant cafe menu experience with live search, category filtering, responsive layouts, glassmorphism effects, and a modern dark navy & purple visual identity.

---

## ✨ Features

* 🔎 **Live Search** — Instantly search through menu items as you type.
* 🗂️ **Category Filtering** — Filter products by menu category with a single click.
* 🔄 **Combined Search & Filtering** — Search works seamlessly together with category filters.
* 📱 **Fully Responsive** — Optimized for desktop, tablet, and mobile screens.
* 🎨 **Modern UI Design** — Dark navy, white, and purple color palette with a premium visual style.
* 🪟 **Glassmorphism Interface** — Elegant translucent panels with blur and subtle borders.
* 🧩 **Dynamic Product Rendering** — Products are generated dynamically using JavaScript.
* 🎯 **Interactive Category Cards** — Each category has its own custom SVG icon and hover animation.
* 💜 **Modern Product Cards** — Clean product presentation with price, icon, favorite button, and action button.
* 🚫 **Empty Search State** — Friendly feedback when no matching product is found.
* 🔢 **Dynamic Product Counter** — Displays the number of currently visible products.
* 🇮🇷 **Persian UI** — Designed specifically for Persian / RTL interfaces.
* ⚡ **Debounced Search** — Search input is optimized using a debounce function for smoother interaction.
* 🧱 **Scalable Structure** — The project is organized so new categories and products can easily be added.

## 🔍 Live Search

The search system allows users to search for menu items in real time.

For example, typing:

```text
Chicken
```

will instantly filter the available products and display matching items.

The search functionality is implemented with JavaScript and uses **debouncing** to prevent unnecessary UI updates while the user is typing.

---

## 🗂️ Smart Category Filtering

Users can select any menu category to instantly display only the products belonging to that category.

The filtering system is completely dynamic and works together with the search functionality.

For example:

```text
Category: Salad
Search: Chicken
```

The interface will only display matching chicken-based salad items.
